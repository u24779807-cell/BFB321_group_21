## Project Title: Smart Spaza Food Network 
project description:
Small food vendors often lack a simple and reliable system for tracking stock and monitoring expiry dates. Thefore this project is going to focus on creating an expiry date and stock monitoring system for small food vendors/Tuckhsops.The project uses html,css,flask and python to create the website.

To run the website, run the app.py file or index.html file to view the dashboard. The Supply chain model is on the inventory.py file. The dashboard is designed to show the user guide,Class A and B inventory ,support and where to add products for the tuckshops.
